## 메인 고정 콘텐츠(P13-T38A/P13-T38B)

기존에 등록된 게시글(Board)/프로그램(Program)을 새로 작성하지 않고 선택해서, 공개 메인 화면 상단에 고정 노출하는 기능이다(신규 콘텐츠 작성 기능이 아니다). 관리자 기능(P13-T38A, 후보 검색 UX는 P13-T38C)과 공개 노출(P13-T38B)로 나뉜다.

### 관리자 기능(P13-T38A/P13-T38C)

- 게시글(Board)/프로그램(Program) 중에서 검색해 고정 추가(공개 상태인 콘텐츠만 고정 가능)
- 대상 유형(게시글/프로그램)과 소분류(게시글: 공지사항/갤러리/자료실/강의 후기, 프로그램: 정규 강좌/특강)로 후보를 필터링하며, 대상 유형·소분류를 변경하면 검색 버튼 없이 즉시 후보 목록이 갱신된다(P13-T38C). 아직 검색으로 확정하지 않은 제목 검색어는 유형/소분류 변경으로 자동 적용되지 않는다.
- 고정 목록 조회(타입/제목/정렬 순서/노출 여부/원본 상태)
- 정렬 순서 변경
- 노출 여부 변경
- 고정 해제
- 고정 개수 제한 없음
- 원본이 이후 비공개로 전환되거나 삭제되어도 고정 레코드는 유지되며, 관리 화면에서 원본 상태(공개/비공개/원본 없음)를 표시한다

### 공개 노출(P13-T38B)

- 공개 메인 화면(`GET /`) 상단, 배너/팝업 영역 다음이자 최신 프로그램 이전에 "주요 소식" 섹션으로 노출한다.
- 관리자가 노출(`visible=true`)로 설정한 고정 콘텐츠만 후보이며, 그중 원본 Board/Program이 실제로 존재하고 공개 상태여야 최종 노출된다. 원본이 비공개이거나 삭제된 고정 콘텐츠는 화면에서 조용히 제외된다(에러 없음).
- 관리자가 지정한 정렬 순서(`sortOrder` 오름차순, 동률이면 `id` 오름차순) 그대로 표시하며, BOARD/PROGRAM 카드가 하나의 목록에 섞여도 순서는 유지된다.
- 노출 개수 제한이 없다.
- 노출할 고정 콘텐츠가 하나도 없으면(고정 자체가 없거나, 전부 노출 대상이 아니거나 원본이 유효하지 않으면) 섹션 자체가 표시되지 않는다.
- 카드 클릭 시 게시글은 게시글 상세, 프로그램은 프로그램 상세로 이동한다. 공개 화면에서는 게시글/프로그램을 구분해 표시하지 않는다.
- 별도의 공개 JSON API는 두지 않는다(공개 화면 렌더링에만 사용).

### 범위 제외

- 게시글/프로그램 외 콘텐츠(기관소개 페이지, 팝업, 배너)는 고정 대상에 포함하지 않는다.
- 신규 홍보 글을 직접 작성하는 기능은 포함하지 않는다.

#### 편집 서식 보존 계약(Phase 15, P15-T4 — CURRENT)

원칙: **CKEditor 툴바 / 자동 서식(Autoformat) / Word 붙여넣기(PasteFromOffice)로 만들 수 있고 이 문서가 지원한다고 표시한 서식은 저장 후에도 의미 있게 보존한다.**

P15-T4 이전에는 편집기에 CKEditor 기본 툴바가 그대로 노출되었지만 저장 시 서버 정제(HtmlSanitizer)가 글머리 기호/번호 목록, 인용, 기울임, 표 머리글 행 구조, 셀 병합을 제거하고 미디어 삽입은 빈 영역만 남겼다. P15-T4 이후 저장부터 아래 지원 서식이 보존된다. 이미 저장된 콘텐츠에서 과거에 사라진 서식은 자동 복구되지 않으며(DB 일괄 수정 없음), 관리자가 다시 편집·저장할 때부터 새 정책이 적용된다.

지원 서식(CURRENT):

| 서식 | 지원 | 비고 |
|---|---|---|
| 제목(Heading) / 굵게 / 기울임 / 링크 | 지원 | 기울임(`<i>`, 기존 `<em>` 포함) 보존 |
| 글머리 기호 목록 / 번호 목록 / 목록 들여쓰기(중첩) | 지원 | 들여쓰기·내어쓰기는 목록 중첩 용도 |
| 인용(blockquote) | 지원 | 공개 상세/팝업/관리자 상세에서 왼쪽 구분선으로 구분 표시 |
| 표 / 표 머리글 행·열 / 셀 병합 | 지원 | 병합 값(colspan/rowspan)은 정수 1~50만 보존, 그 외 값은 병합 정보만 제거되고 셀 내용은 유지 |
| 이미지 업로드 / 정렬 / 크기(25·50·75%) / 대체 텍스트 / 캡션 | 지원 | 기존 정책 유지 |
| 미디어 삽입(YouTube 등 embed) | **미지원** | 툴바와 편집기 플러그인에서 제거(동영상 URL을 붙여넣어도 일반 텍스트로 남음) |
| 지도 embed(iframe) | **미지원** | 오시는 길은 지도 이미지 + 외부 지도 링크로 작성 |

# 15. 관리자 비밀번호 변경(CURRENT — P15-T6)

로그인한 관리자가 본인 비밀번호를 변경한다. 관리자 화면 header의 로그아웃 버튼 옆 "비밀번호 변경" 링크로 `/admin/password` 화면에 진입한다(sidebar 메뉴 항목은 아니다).

### 기능

- 입력: 현재 비밀번호, 새 비밀번호, 새 비밀번호 확인(3개 모두 필수)
- 새 비밀번호 정책(`docs/CODING_RULES.md`): 8자 이상 64자 이하, 영문/숫자/특수문자 중 2종 이상, 공백과 한글 등 비ASCII 문자 사용 불가. 화면에 정책 안내를 표시한다
- "새 비밀번호 확인"은 화면에서만 새 비밀번호와 비교하며, 다르면 서버에 요청하지 않고 오류를 표시한다(서버 API로 보내지 않는다)
- 현재 비밀번호와 같은 새 비밀번호는 거부
- 현재 비밀번호가 틀리면 "현재 비밀번호가 올바르지 않습니다." 오류를 표시하고 로그인 상태는 유지
- 정책 위반은 서버가 알려준 정책 문구를 표시
- 변경 성공 시 성공 안내를 표시하고 입력값을 모두 비운다. 로그인 상태는 유지된다(세션 ID만 교체)

### 범위 제외

- 비밀번호 찾기 / 이메일 발송 / 재설정 UI
- 다른 관리자 계정 생성·관리
- 비밀번호 분실 시 재설정은 운영 절차(`docs/OPERATIONS.md`, P15-T8에서 작성 예정)로 처리

# 16. 공개 화면 오류 페이지(CURRENT — P15-T5)

P15-T5 이전에는 공개 화면에서 존재하지 않거나 비공개인 게시글/프로그램, 잘못된 기관소개 페이지 주소, 존재하지 않는 주소로 접근하면 JSON 오류 본문이 그대로 표시되었다.

**현재(CURRENT)**:

- 공개 화면 주소(HTML)에서 오류가 나면 방문자용 안내 페이지를 표시하며, HTTP 상태 코드는 그대로 유지된다.
  - 404 "페이지를 찾을 수 없습니다": 없는/비공개 게시글·프로그램, 잘못된 기관소개 페이지 주소(예: `/pages/NOPE`), 숫자가 아닌 상세 번호(예: `/boards/abc`), 존재하지 않는 주소(예: `/no-such-path`)
  - 400 "잘못된 요청입니다": 목록의 잘못된 분류/정렬 값(예: `/boards?boardType=NOPE`, `/boards?sort=nope,desc`)
  - 500 "일시적인 오류가 발생했습니다": 그 외 서버 오류(DB/메뉴 장애 포함)
- 안내 페이지는 오류 코드, 제목, 짧은 설명, "홈으로 가기" 링크만 표시하고, 내부 오류 정보(예외, 경로, SQL, 오류 코드명)는 노출하지 않는다. 공통 header/footer/메뉴 없이 독립적으로 표시되며 JavaScript를 사용하지 않는다.
- `/api/**`는 기존대로 JSON 오류 응답을 유지한다.
- 관리자 상세 화면 안에서 발생한 404(예: 없는 게시글 상세)는 Phase 15 범위 밖이며 JSON 응답을 유지한다. 로그인 상태에서 어떤 화면에도 해당하지 않는 관리자 주소는 위 404 안내 페이지로 표시된다.
