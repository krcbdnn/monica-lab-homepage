# PRD (Product Requirements Document)

이 프로젝트는 일반 회원 기능이 없는 교육기관 홈페이지(CMS)입니다.

일반 사용자는 로그인 없이 홈페이지를 이용하며,
수강 신청과 특강 신청만 가능합니다.

관리자만 Spring Security를 통해 로그인할 수 있습니다.

회원가입, 마이페이지, 일반 로그인, 비밀번호 찾기 기능은 구현하지 않습니다.

모든 관리자 기능은 /admin 경로 아래에 구현합니다.

## 프로젝트 개요

교육기관 홈페이지(CMS) 구축 프로젝트

### 목적

* 기관 소개 및 프로그램 안내
* 공지사항 및 자료 제공
* 수강 신청 및 특강 신청 접수
* 관리자가 홈페이지 콘텐츠를 손쉽게 관리할 수 있는 CMS 제공
