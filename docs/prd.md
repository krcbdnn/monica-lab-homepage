# PRD - 모니카 연구소 홈페이지 및 CMS

## 1. 프로젝트 개요

### 프로젝트명

모니카 연구소 홈페이지 및 CMS

### 프로젝트 목적

* 연구소 소개 및 연구 성과 홍보
* 공지사항 및 연구자료 제공
* 방문자 문의 접수
* 관리자의 콘텐츠 운영 지원

### 개발 목적

* 실제 운영 가능한 홈페이지 구축
* CMS 기능 구현
* 백엔드 포트폴리오 제작
